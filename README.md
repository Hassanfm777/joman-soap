# موقع جُمان للصابون - دليل الاستخدام

## 1) نشر الموقع على GitHub Pages
1. سوّي حساب على github.com (لو ما عندك).
2. أنشئي مستودع (Repository) جديد، سميه مثلاً `joman-soap`.
3. ارفعي كل ملفات هالمجلد لجوا المستودع (index.html, css, js, images).
4. من إعدادات المستودع Settings → Pages، اختاري:
   - Source: Deploy from a branch
   - Branch: main / (root)
5. احفظي، وبعد دقيقتين رح يصير عندك رابط شكله:
   `https://username.github.io/joman-soap/`

## 2) كيف بتوصلك إشعارات الطلبات
الموقع فيه طريقتين للطلب:

**أ) زر واتساب على كل منتج**
لما الزبون يضغط "اطلب عبر واتساب" بتفتح له محادثة واتساب فيها رسالة جاهزة
باسم المنتج، وترسلها مباشرة إلك. هاي أسهل وأسرع طريقة إشعار.

لازم تغيّري رقمك في ملف `js/script.js`:
```js
const WHATSAPP_NUMBER = "9627XXXXXXXX";
```
اكتبي رقمك بالصيغة الدولية بدون + وبدون صفر البداية
(مثال: لو رقمك 0791234567 يصير 9627911234567)

**ب) نموذج الطلب في نهاية الصفحة**
هاد بيرسل الطلب كإيميل إشعار إلك، عن طريق خدمة اسمها Formspree (مجانية):
1. روحي لموقع formspree.io وسوّي حساب مجاني.
2. أنشئي فورم جديد (New Form) وحطي إيميلك.
3. بيعطوكي رابط شكله `https://formspree.io/f/xxxxxxx`
4. افتحي `index.html` ولاقي هالسطر:
   ```html
   <form id="order-form" ... action="https://formspree.io/f/YOUR_FORM_ID" ...>
   ```
5. استبدلي `YOUR_FORM_ID` برقم الفورم يلي عطوكي ياه.
6. كل ما حد يعبي الفورم ويرسل، بوصلك إيميل فيه كل التفاصيل.

## 3) خيار الدفع
GitHub Pages موقع "ثابت" (Static) يعني ما فيه سيرفر ولا قاعدة بيانات،
فما فيه إمكانية تبني بوابة دفع كاملة من الصفر جواه. بس عندك خيارين واقعيين:

- **الدفع عند الاستلام (COD):** الأسهل والأشيع بالأردن، وهو يلي مفعّل افتراضيًا
  بالموقع (الزبون يطلب، وتتفقوا على الدفع وقت التوصيل).

- **رابط دفع جاهز:** لو بدك دفع إلكتروني، أسهل حل إنك تسوّي حساب على بوابة
  دفع محلية أو عالمية (زي PayPal، أو أي بنك/بوابة أردنية متل CliQ أو حسابات
  الدفع الإلكتروني)، وياخذوكي رابط دفع جاهز، وتضيفي هاد الرابط كزر "ادفع الآن"
  جنب كل منتج أو بصفحة الطلب. الدفع نفسه بيصير عبر صفحتهم هم، مش عبر موقعك.
  إذا حبيتي هيك زر، قوليلي وبضيفه.

## 4) كيف تضيفي منتج جديد أو صورة جديدة
كل المنتجات موجودة بملف واحد بس: `js/products.js`

1. ارفعي صورة المنتج داخل مجلد `images/` بالمستودع (من GitHub مباشرة:
   افتحي مجلد images → Add file → Upload files).
2. افتحي `js/products.js` وضيفي سطر جديد بنفس شكل باقي المنتجات:
   ```js
   {
     name: "اسم المنتج",
     desc: "وصف قصير للمنتج",
     price: "3.5 دينار",
     color: "#7C8A57",
     image: "images/اسم_الصورة.jpg"
   },
   ```
3. احفظي التعديل (Commit changes) وبتظهر المنتج تلقائيًا بالموقع خلال ثواني.

لو ما ضفتي صورة (تركتي `image: ""`), رح يظهر مكانها شكل قالبة صابون
بلون تختاريه من حقل `color`، لحد ما تجهزي الصور الحقيقية.

## ملاحظة أخيرة
كل التعديلات (منتجات، أسعار، رقم واتساب) بتصير بتعديل ملفات نصية بسيطة
مباشرة من موقع github.com بالمتصفح، ما بتحتاجي أي برنامج إضافي.
